After downloading

  • Double-click the .exe. The installer opens; press Install.
  • If Windows shows “Windows protected your PC”, choose More info → Run anyway. This appears for new, not-yet-widely-downloaded programs.
  • Open the .dmg, then double-click the installer inside it (no need to drag anything).
  • If macOS says the app “cannot be opened”, right-click (or Control-click) it and choose Open, then Open again. This is only needed the first time.
  • AppImage: make it executable (right-click → Properties → “Allow executing”, or chmod +x), then double-click.
  • Debian / Ubuntu: download the .deb instead and double-click it to install with your software center.

Already have Omnistall?

If any Omnistall installer has run on this computer before, you can download the small .omni file instead and double-click it. It works the same on every operating system.
